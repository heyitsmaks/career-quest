# Career Quest

Рабочее название личного приложения для долгосрочных целей, проектов и обучения.

## Идея

Интерактивный игровой мир помогает видеть общую картину, приоритеты, зависимости и путь к самостоятельно выбранному дедлайну. Проекты, книги и темы представлены объектами, которые можно открыть и изучить подробнее.

## Статус

Обсуждение продукта и визуальных направлений. Приложение ещё не реализовано и не опубликовано. Название, игровой формат, интерфейс и технологии пока не выбраны.

## Личные данные

Репозиторий содержит общую концепцию и дизайн-материалы. Персональные планы, история переписки, реальные показатели и секреты хранятся вне отслеживаемых файлов. Для локальных материалов предусмотрена игнорируемая папка `private/`.

## Следующий этап

Согласовать опыт использования и визуальное направление, затем получить окончательную карту целей с дедлайнами и определить первую версию.
