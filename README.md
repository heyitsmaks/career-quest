# Career Quest

Рабочее название личного приложения для долгосрочных целей, проектов и обучения.

## Экспедиция

Откройте `index.html` в браузере. Полёт к первому дому начинается при открытии карты. После подтверждения результата приложение сразу открывает следующую станцию. «На сегодня всё» сохраняет незавершённый шаг, страницу и итог сессии. Атлас служит справочником по целям.

Полёт идёт от первого лица между шестью горными станциями. У каждой станции есть освещённая доска. Для книг карта указывает диапазон страниц, для AI — короткий список терминов для самостоятельного поиска. Проекты возвращаются как напоминания, пока их не снимут в атласе. Потяните экран, чтобы осмотреться, или удерживайте ускорение во время перелёта. Для трёхмерной камеры требуется WebGL2. Журнал и занятия работают и с обычной панорамой.

Для персональной версии выполните `python build_personal.py` с локальным файлом `private/plan.json`. Публичная демонстрация в `index.html` показывает структуру данных. Персональная HTML-страница включает все ресурсы и открывается офлайн. Автономная копия сохраняет прогресс на этом устройстве. Размещённая персональная версия использует вход через ChatGPT и серверное сохранение с проверкой версии; один аккаунт продолжает один маршрут с компьютера или телефона.

Сборка 3D-сцены после изменений в `world.js` или `islands.js` выполняется командами `npm ci` и `npx esbuild world.js --bundle --minify --outfile=world.bundle.js`. Лицензия Three.js находится в `assets/three-LICENSE.txt`.

## Личные данные

Репозиторий содержит общую концепцию и дизайн-материалы. Персональные планы, история переписки, реальные показатели и секреты хранятся вне отслеживаемых файлов. Для локальных материалов предусмотрена игнорируемая папка `private/`.
