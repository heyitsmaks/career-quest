# Career Quest

Рабочее название личного приложения для долгосрочных целей, проектов и обучения.

## Идея

Интерактивный игровой мир помогает видеть общую картину, приоритеты, зависимости и путь к самостоятельно выбранному дедлайну. Проекты, книги и темы представлены объектами, которые можно открыть и изучить подробнее.

Программа занятий превращает большую карту в конкретный следующий шаг. Длина сессии свободная; прогноз к дедлайну учитывает реальные результаты и темп. Первая версия должна быть удобна и на компьютере, и на телефоне.

## Статус

Работает локальный прототип. Откройте `index.html` в браузере. На карте можно выбрать направление, ответить на вводный вопрос, начать занятие и сохранить результат с закладкой. Состояние хранится в локальном хранилище браузера.

Для личной карты подготовьте `private/plan.json` по структуре данных из элемента `plan` в демонстрации и выполните `python build_personal.py`. В папке `private/` появится автономный HTML с картой и материалами. При изменении данных сохраняйте идентификаторы направлений и порядок существующих этапов, поскольку история ссылается на них.

## Личные данные

Репозиторий содержит общую концепцию и дизайн-материалы. Персональные планы, история переписки, реальные показатели и секреты хранятся вне отслеживаемых файлов. Для локальных материалов предусмотрена игнорируемая папка `private/`.

## Следующий этап

Проверить удобство сессий в обычном использовании и выбрать художественный стиль. Расчёт среднего времени использует введённую оценку работы и число оставшихся занятий. Синхронизация между устройствами и автоматический прогноз по истории относятся к следующей версии.
