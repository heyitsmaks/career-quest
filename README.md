# Career Quest

Рабочее название личного приложения для долгосрочных целей, проектов и обучения.

## Экспедиция

Откройте `index.html` в браузере. Кнопка «Начать путь» запускает последовательную экспедицию. После подтверждения результата приложение сразу открывает следующую станцию. «На сегодня всё» сохраняет незавершённый шаг, страницу и итог сессии. Атлас служит справочником по целям.

Панорама дополнена трёхмерным дирижаблем. «Облететь в 3D» открывает объёмный мир островов, который вращается перетаскиванием. Для трёхмерной камеры требуется WebGL2. Журнал и занятия работают и с обычной панорамой.

Для персональной версии выполните `python build_personal.py` с локальным файлом `private/plan.json`. Публичная демонстрация в `index.html` показывает структуру данных. Персональная HTML-страница включает все ресурсы и открывается офлайн. Прогресс хранится в браузере устройства.

Сборка 3D-сцены после изменений в `world.js` или `islands.js` выполняется командами `npm ci` и `npx esbuild world.js --bundle --minify --outfile=world.bundle.js`. Лицензия Three.js находится в `assets/three-LICENSE.txt`.

## Личные данные

Репозиторий содержит общую концепцию и дизайн-материалы. Персональные планы, история переписки, реальные показатели и секреты хранятся вне отслеживаемых файлов. Для локальных материалов предусмотрена игнорируемая папка `private/`.
